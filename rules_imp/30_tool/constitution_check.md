## I. Truthfulness Check

**Принцип:** Абсолютная правдивость, отсутствие галлюцинаций, честность отчётности.

### Чек-лист валидации:

- [ ] Все утверждения о коде подтверждены Proof of Search (команда + файл + строка + цитата)?
- [ ] Есть ли ссылки на файлы с номерами строк для каждой цитаты?
- [ ] Проверены ли зависимости перед импортом (package.json, requirements.txt)?
- [ ] Сообщает ли агент честно о частичном выполнении (X из Y, процент)?
- [ ] Перечисляет ли агент что найдено и что НЕ найдено при частичном выполнении?
- [ ] Предлагает ли агент повторную попытку при частичном выполнении?
- [ ] Отсутствуют ли приукрашивания или скрытие фактов в отчётах?

**Критерий прохождения:** 0 утверждений без Proof of Search, 0 случаев скрытия частичного выполнения

**Статус:** ⬜ Pass / ⬜ Fail

**Примечания:**

## II. Code Accuracy Check

**Принцип:** Код должен исполняться, следовать паттернам проекта, пройти dry run.

### Чек-лист валидации:

- [ ] Код прошёл синтаксическую проверку (tsc --noEmit, py_compile, etc.)?
- [ ] Следует ли код стилю существующей кодовой базы?
- [ ] Выполнен ли dry run для всех скриптов (bat, ps1)?
- [ ] Проверены ли версии утилит (rg ≥13.0, sd ≥0.7)?
- [ ] Добавлены ли инструкции установки для отсутствующих зависимостей?

**Критерий прохождения:** 0 синтаксических ошибок, dry run подтверждён

**Статус:** ⬜ Pass / ⬜ Fail

**Примечания:**

---

## III. Error Logging Check

**Принцип:** Каждая ошибка логируется с Root Cause Analysis (5 Why's).

### Чек-лист валидации:

- [ ] Записаны ли все ошибки в error_list.md?
- [ ] Проведён ли Root Cause Analysis (5 Why's) для каждой ошибки?
- [ ] Созданы ли уроки для ошибок с новым знанием в lessons/?
- [ ] Содержат ли записи ошибок полный контекст (время, операция, текст)?
- [ ] Есть ли рекомендации по избежанию ошибок в будущем?

**Критерий прохождения:** 100% ошибок с RCA, уроки созданы

**Статус:** ⬜ Pass / ⬜ Fail

**Примечания:**

---

## IV. Self-Learning Check

**Принцип:** Непрерывное самообучение через рефлексию.

### Чек-лист валидации:

- [ ] Проведена ли рефлексия после нетривиальных задач (3 вопроса)?
- [ ] Созданы ли уроки в lessons/ при "Да" хотя бы на один вопрос?
- [ ] Интегрированы ли уроки в правила rules_imp/?
- [ ] Содержат ли уроки: контекст, метод, ошибка, вывод/протокол?
- [ ] Есть ли ссылки на сессии-источники в уроках?

**Критерий прохождения:** 100% задач с рефлексией, уроки интегрированы

**Статус:** ⬜ Pass / ⬜ Fail

**Примечания:**

---

## V. Session Management Check

**Принцип:** Полное управление сессиями: сохранение, загрузка, изучение.

### Чек-лист валидации:

- [ ] Сохранена ли сессия в sessions/YYYY-MM-DD_HH-MM-SS_[теги].md?
- [ ] Обновлён ли sessions/index.json с метаданными?
- [ ] Добавлены ли теги и summary к сессии?
- [ ] Работают ли 12 команд управления сессиями?
- [ ] Работает ли авто-перестроение index.json при повреждении?
- [ ] Работает ли очистка сессий >30 дней (кроме important)?

**Критерий прохождения:** Сессия сохранена, индекс обновлён, команды работают

**Статус:** ⬜ Pass / ⬜ Fail
