# 🧠 Memory Strategy: Алгоритм "Консервации" Сессии

## 🚨 Пороги Контекста (Limit 128K-200K)
- 🟡 **25K (Warning)**: Предупредить пользователя.
- 🔴 **30K (Critical)**: Начать процедуру "Консервации" (Save to Disk).

## 🛡️ Зоны Безопасности (НИКОГДА не удалять из RAM)
1. **[SYSTEM]**: `AGENTS.md`, `DIRECTIVE.md`.
2. **[TASK]**: Текущая задача или `todo.md` и последние 5 пар Q-A.
3. **[SETUP]**: Начальные 4 сообщения сессии.

## 🔄 Протокол "Консервации" (Вместо удаления)
Если контекст переполнен, ПЕРЕД очисткой RAM:
1. **Суммируй**: Сожми `[HISTORY]` (середина диалога) в ключевые тезисы.
2. **Сохрани "Сало"**: Запиши удаляемые данные (код, старые обсуждения) в файл:
   `.\sessions\id_session_dd-mm-yyyy_hh-mm.md` (plain text).
## 📦 Иерархия Приоритетов (Удаление из RAM -> На Диск)
1. `code_listings` (Удалять ПЕРВЫМИ, они есть в файлах проекта).
2. `detailed_descriptions` (Суммировать в 1 предложение).
3. `plot_developments` (Ключевые события — в лог, детали в "Сало").

## 📝 Жесткие правила
- **ЧИСТКА != УДАЛЕНИЕ**: Очистка RAM — это перенос знаний на HDD.
- **FILE SAFETY**: Категорически ЗАПРЕЩЕНО удалять любые файлы с расширением `.md`, `.py`, `.log`, `.txt` без прямой команды пользователя "DEL".
- **ОШИБКИ**: Сохраняй связку "Ошибка -> Решение" в `errors.md` перед очисткой.

## Правило "Живого Анализа" (Anti-Scribe):
- **Суммирование вместо копирования**: Если читаешь файл >10KB, ЗАПРЕЩЕНО просто цитировать его части. 
- **Задача**: Прочитай, выдели 5-7 ключевых фактов/логических связей, запиши их в текущий контекст и ЗАБУДЬ исходный текст. 
- **Результат**: В памяти должна остаться "выжимка смысла", а не "сырой текст".
