## ПРИОРИТЕТ ПРАВИЛ

### Уровень 1: КОНСТИТУЦИЯ (Абсолютный приоритет)
- **Файл:** `rules_imp/00_core/constitution.md`
- **Статус:** НЕИЗМЕНЯЕМ
- **Содержимое:** 5 принципов управления поведением
- **При конфликте:** Перекрывает ВСЕ остальные правила

---

### Уровень 2: ДИРЕКТИВЫ ПОЛЬЗОВАТЕЛЯ
- **Файл:** `rules_imp/00_core/directives.md`
- **Статус:** Требуют подтверждения
- **Содержимое:** Триггеры, личные установки
- **При конфликте:** Уступает только Конституции

---

### Уровень 3: УРОКИ ТЕКУЩЕЙ СЕССИИ
- **Локация:** `C:/CLI/Pi/lessons/SESSION_[ID]/`
- **Статус:** Применяются автоматически
- **Содержимое:** Уроки, извлеченные в текущей сессии
- **Приоритет:** Выше общих уроков

---

### Уровень 4: ОБЩИЕ УРОКИ
- **Локация:** `C:/CLI/Pi/lessons/*.md`
- **Сортировка:** По дате (новые > старые)
- **Приоритет:** CRITICAL > HIGH > MEDIUM > LOW

---

### Уровень 5: ПРОТОКОЛЫ ПРОЦЕССОВ
- **Локация:** `rules_imp/10_proc/p_*.md`
- **Исполнение:** Строгое, последовательное
- **Примеры:** p_start.md, p_loop.md, p_error_logging.md

---

### Уровень 6: НАВЫКИ
- **Локация:** `rules_imp/20_skill/s_*.md`
- **Применение:** По ситуации
- **Примеры:** s_proof_of_search.md, s_code_accuracy.md

---

### Уровень 7: ИНСТРУМЕНТЫ
- **Локация:** `rules_imp/30_tool/*.py`
- **Назначение:** Вспомогательные
- **Примеры:** gatekeeper.py, session_gate.py

---

### Уровень 8: WORK FILES (Локальные)
- **Локация:** Текущий проект (`./`)
- **Файлы:** instruct.md, spec.md, ts.md, todo.md
- **Приоритет:** Самый низкий

## ПРАВИЛА РАЗРЕШЕНИЯ КОНФЛИКТОВ

### Сценарий 1: Прямой конфликт

**Пример:** `directives.md` говорит X, `p_start.md` говорит Y.

**Решение:**
1. Проверить иерархию (directives.md выше)
2. Следовать directives.md
3. **Зафиксировать конфликт** в `rules_imp/_conflicts_log.md`

### Сценарий 2: Неопределенность

**Пример:** Нет четкого правила для ситуации.

**Решение:**
1. Применить ближайший по смыслу принцип из constitution.md
2. Запросить уточнение у пользователя
3. **Создать урок** с новым правилом

### Сценарий 3: Взаимное противоречие

**Пример:** Два файла одного уровня говорят противоположное.

**Решение:**
1. Остановиться
2. Сообщить пользователю о конфликте
3. Запросить решение
4. **Не действовать** до разрешения

## ЖЕСТКИЕ ТРЕБОВАНИЯ V3

### Блокировка при отсутствии lesson
- **Триггер:** Попытка открыть сессию
- **Проверка:** Есть ли lesson в `C:/CLI/Pi/lessons/`?
- **Действие:** Без lesson → сессия не открывается

### Блокировка неверных путей
- **Триггер:** Отправка команды в bash
- **Проверка:** Путь соответствует правилам `path.md`?
- **Действие:** Неверный путь → команда не уходит

### Автосоздание lesson при ошибке
- **Триггер:** Любая ошибка
- **Действие:** Автоматическое создание `lesson_YYYY-MM-DD_ERROR_*.md`
- **Вопросы:** Нет, безусловно
