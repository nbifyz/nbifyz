# Work Files Protocol

## 📁 Описание рабочих файлов проекта

- **`.\AGENTS.md`** - Основной файл инструкций агента (этот протокол)
  * Содержит ключевые правила, протоколы и поведенческие директивы
  
- **`.\instruct.md`** - Индивидуальные инструкции для текущего проекта
  * Специфические указания от пользователя по текущей задаче
  
- **`.\spec.md`** - Спецификации и технические требования
  * Детальное описание целей, функциональности и оtt yflj  граничений проекта
  
- **`.\todo.md`** - Список текущих задач и элементов TODO
  * Планирование, контроль прогресса, список задач на реализацию
  
- **`.\ts.md`** - Информация о TypeScript (типизация, кодовые заметки)
  * Техническая документация, примеры кода, типы данных
  
- **`.\error_list`** - Журнал ошибок и проблем
  * Регистрация, анализ и отслеживание выявленных ошибок

-**`.\check_list.md`** Чек лист планируемых действий сложных проверок или планирования 
## 📝 Рекомендации по работе

- Все файлы находятся в рабочем каталоге проекта (Workdir R/W)
- Приоритет директив 
1. `instruct.md` 
2. `ts.md` 
3.  `AGENTS.md`
- При изменениях НЕОБХОДИМО запросить пользователя и сделать резервные копии
- Согласовывать ЛЮБЫЕ изменения с пользователем
