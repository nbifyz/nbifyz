## Мгновенное Решение Ошибок Доступа к Файлам

**Версия:** 1.0
**Приоритет:** 🔴 КРИТИЧНО — Открывать при ЛЮБОЙ ошибке доступа
**Время диагностики:** 30 секунд

## 🚨 АЛГОРИТМ: НЕ ДУМАТЬ, А ДЕЙСТВОВАТЬ

При получении `EPERM`, `EACCES` или любой ошибки доступа:

### ШАГ 1: Проверка Атрибута IsReadOnly (10 сек)

**Команда:**
```powershell
Get-ItemProperty -Path "ПОЛНЫЙ_ПУТЬ_К_ФАЙЛУ" | Select-Object IsReadOnly
```

**Если `IsReadOnly: True` → Решение немедленно:**
```powershell
Set-ItemProperty -Path "ПОЛНЫЙ_ПУТЬ_К_ФАЙЛУ" -Name IsReadOnly -Value $false
```

✅ **После этого попробовать операцию снова.**

---

### ШАГ 2: Проверка Блокировки Процессом (10 сек)

**Если файл не Read-Only, но доступа нет:**

```powershell
# Проверить, не открыт ли файл другим процессом
Get-Process | Where-Object {$_.Modules -match "ИМЯ_ФАЙЛА"} 2>$null
```

**Или:**
```powershell
# С помощью Resource Monitor (если доступно)
resmon.exe
```

**Если файл заблокирован → Закрыть приложение/процесс**

---

### ШАГ 3: Проверка Прав Доступа (10 сек)

**Если не Read-Only и не заблокирован:**

```powershell
Get-Acl "ПОЛНЫЙ_ПУТЬ_К_ФАЙЛУ" | Format-List
```

**Если прав недостаточно → Обратиться к пользователю**

## ❌ ЧТО НЕЛЬЗЯ ДЕЛАТЬ

| Антипаттерн | Почему плохо |
|-------------|--------------|
| Пытаться переименовать файл | Не решит проблему, потратит время |
| Пытаться создать копию | Избыточно, не диагностирует причину |
| Искать "обходные пути" | EPERM решается за 30 сек через IsReadOnly |
| Сразу писать урок | Сначала решить проблему, потом документировать |
| Обвинять "систему" | Диагностика → решение → документирование |

## 📋 БЫСТРАЯ ШПАРГАЛКА

### PowerShell One-Liner (Копировать-Вставить)

```powershell
# Снять Read-Only с конкретного файла
Set-ItemProperty -Path "C:\CLI\Pi\rules_imp\00_core\constitution.md" -Name IsReadOnly -Value $false

# Снять Read-Only со ВСЕХ файлов в папке
Get-ChildItem "C:\CLI\Pi\rules_imp\*" -File | ForEach-Object { Set-ItemProperty -Path $_.FullName -Name IsReadOnly -Value $false }
```

### Batch Альтернатива

```batch
attrib -R "C:\CLI\Pi\rules_imp\00_core\constitution.md"
```
