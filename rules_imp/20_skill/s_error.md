# ⚠️ Скилл 4: Обработка ошибок

## Правило

**ВСЕГДА** предусматривать обработку исключительных ситуаций.

## Шаблон

```python
def safe_function(data):
    try:
        # Основная логика
        result = process(data)
        return result
    except Exception as e:
        # Логирование ошибки
        logger.error(f"Error: {e}")
        # Возврат в известное состояние
        return None
```

## Что логировать

- ✅ Тип ошибки
- ✅ Входные данные
- ✅ Место ошибки
- ✅ Трассировку стека

## Принципы

1. **Не глушить ошибки** без логирования
2. **Возвращать** в известное состояние
3. **Предоставлять** контекст для отладки
