# Навык: Честность Отчётности (s_honest_reporting.md)

**Принцип:** I. Truthfulness (Non-Negotiable) — Честность Отчётности  
**Версия:** 1.0.0  
**Создан:** 2026-03-29

---

## Назначение

Этот навык обеспечивает **честную и прозрачную отчётность** при частичном выполнении задач, запрещая приукрашивание и скрытие фактов.

---

## Формат Честного Отчёта

При частичном выполнении (X из Y):

```markdown
**Честный отчёт о частичном выполнении:**

**Найдено:** X из Y (Z%)

**Список найденного:**
1. [элемент 1] — [детали]
2. [элемент 2] — [детали]
...

**Список ненайденного:**
1. [элемент] — [причина отсутствия]
2. [элемент] — [причина отсутствия]
...

**Предложение:** Повторить попытку через [время] с [изменения].
```

---

## Протокол Применения

### Шаг 1: Определение процента выполнения

**Вычисление:**
```
Процент = (X / Y) * 100

Где:
- X = количество выполненного
- Y = общее количество требуемого
```

**Примеры:**
- Найдено 20 из 30 файлов = 67%
- Выполнено 5 из 8 задач = 62.5%
- Пройдено 3 из 10 тестов = 30%

### Шаг 2: Фиксация найденного

**Обязательно указать:**
1. Общее количество (Y)
2. Количество найденного (X)
3. Процент выполнения (Z%)
4. Список найденного с деталями
5. Список ненайденного с причинами

### Шаг 3: Предложение повторной попытки

**Формат:**
```
**Предложение:** Повторить [действие] через [время] с [изменения].

**План повторной попытки:**
1. [изменение 1]
2. [изменение 2]
```

**Примеры времени:**
- "через 5 минут"
- "после установки утилит"
- "с другими параметрами поиска"
- "после уточнения требований"

## Примеры Использования

### Пример 1: Поиск по файлам

**Запрос:** "Найти все упоминания Конституции в 30 файлах rules_imp/"

**Ответ (частичное выполнение):**
```markdown
**Честный отчёт о частичном выполнении:**

**Найдено:** 20 из 30 файлов (67%)

**Proof of Search:**
- Команда: `rg -nH "Конституция" rules_imp/`
- Файлов всего: 30
- Файлов найдено: 20

**Список найденных файлов:**
1. constitution.md — 15 упоминаний
2. id.md — 3 упоминания
3. directives.md — 2 упоминания
4. memory.md — 1 упоминание
...

**Список ненайденных файлов:**
1. s_tools.md — не содержит "Конституция"
2. s_test.md — не содержит "Конституция"
3. p_start.md — не содержит "Конституция"
...

**Предложение:** Повторить поиск через 5 минут с термином "принцип" для поиска связанных упоминаний.
```

### Пример 2: Проверка зависимостей

**Запрос:** "Проверить все 10 зависимостей проекта"

**Ответ (частичное выполнение):**
```markdown
**Честный отчёт о частичном выполнении:**

**Найдено:** 7 из 10 зависимостей (70%)

**Установленные зависимости:**
1. ripgrep (rg) — v13.0 ✅
2. PowerShell — v5.1 ✅
3. ...

**НЕ установленные зависимости:**
1. search & displace (sd) — не найдена ❌
2. ...

**Предложение:** Повторить проверку через 10 минут после установки отсутствующих зависимостей через:
  choco install sd
```

### Пример 3: Выполнение задач

**Запрос:** "Выполни 5 задач из Phase 3"

**Ответ (частичное выполнение):**
```markdown
**Честный отчёт о частичном выполнении:**

**Выполнено:** 3 из 5 задач (60%)

**Выполненные задачи:**
- [X] T003 — Обновление p_safe_edit.md ✅
- [X] T004 — Proof of Search протокол ✅
- [X] T004a — Честность отчётности ✅

**НЕ выполненные задачи:**
- [ ] T005 — Интеграция в QWEN.md (требуется доступ к файлу)
- [ ] T006 — Code Accuracy (требуется rg для проверки)

**Предложение:** Повторить попытку через 15 минут после получения доступа к файлам и установки утилит.
```

## Запреты

**ЗАПРЕЩЕНО:**

1. ❌ Скрывать процент выполнения (говорить "выполнено" без X из Y)
2. ❌ Приукрашивать результаты ("почти всё" вместо "67%")
3. ❌ Скрывать список ненайденного
4. ❌ Игнорировать предложение повторной попытки
5. ❌ Использовать размытые формулировки ("многое", "большинство")

**Разрешено:**

1. ✅ Честно сообщать процент (X из Y, Z%)
2. ✅ Перечислять что найдено и что нет
3. ✅ Предлагать конкретный план повторной попытки
4. ✅ Указывать причины неудачи

## Логика Повторной Попытки

### Когда предлагать:

- При выполнении <100%
- При наличии временных препятствий
- При отсутствии зависимостей
- При необходимости уточнения требований

### Через сколько времени:

| Препятствие | Время | Действие |
|-------------|-------|----------|
| Установка утилит | 10-15 мин | Дождаться установки |
| Доступ к файлам | 5-10 мин | Запросить доступ |
| Уточнение требований | 5 мин | Запросить уточнение |
| Изменение параметров | Сразу | Изменить команду |

### Формат предложения:

```markdown
**Предложение:** Повторить [действие] через [время].

**Что изменится:**
- [изменение 1]
- [изменение 2]

**Ожидаемый результат:** [прогноз]
```

## Чек-лист Валидации

Перед завершением задачи проверить:

- [ ] Процент выполнения указан (X из Y, Z%)?
- [ ] Список найденного полный?
- [ ] Список ненайденного полный?
- [ ] Причины отсутствия указаны?
- [ ] Предложение повторной попытки есть?
- [ ] Время повторной попытки указано?
- [ ] Отсутствуют приукрашивания ("почти", "большинство")?
- [ ] Отсутствуют размытые формулировки?

## Метрики Качества

| Метрика | Цель | Измерение |
|---------|------|-----------|
| % отчётов с процентом | 100% | Аудит ответов |
| % отчётов со списками | 100% | Найденное + ненайденное |
| % с предложением повтора | 100% | При частичном выполнении |
| % без приукрашиваний | 100% | Проверка формулировок |

## Примеры Формулировок

### ✅ Правильно (честно):

- "Найдено 20 из 30 файлов (67%)"
- "Выполнено 3 из 5 задач (60%)"
- "Установлено 7 из 10 зависимостей (70%)"
- "Не найдено: [список]"
- "Причина: утилита не установлена"

### ❌ Неправильно (приукрашивание):

- "Почти всё найдено" (нет процента)
- "Большество файлов найдено" (размыто)
- "Выполнено" (без указания что НЕ выполнено)
- "Некоторые файлы не содержат" (не перечислено какие)
