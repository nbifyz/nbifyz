## Назначение

Этот навык обеспечивает **выполнение сухих прогонов** для анализа логики кода без фактического выполнения.

---

## Протокол Dry Run

### Шаг 1: Статический анализ

**Перед выполнением:**
1. Прочитать код построчно
2. Отследить поток данных
3. Проверить обработку ошибок

### Шаг 2: Трассировка логики

**Для каждой функции:**
1. Входные данные → Обработка → Выходные данные
2. Проверить граничные условия
3. Проверить обработку исключений

### Шаг 3: Проверка побочных эффектов

**Убедиться:**
1. Нет незапланированных изменений файлов
2. Нет утечек памяти/ресурсов
3. Нет блокировок (deadlock)

---

## Протокол Применения

### Для скриптов (bat, ps1)

```bash
# PowerShell: анализ без выполнения
powershell -NoProfile -Command "Get-Content файл.ps1"

# Batch: вывод содержимого
type файл.bat
```

### Для кода (ts, py, rs)

```bash
# TypeScript: компиляция без вывода
tsc --noEmit файл.ts

# Python: компиляция без выполнения
python -m py_compile файл.py

# Rust: проверка без компиляции
cargo check
```

## Чек-лист Dry Run

**Для каждой задачи:**

- [ ] Код прочитан построчно
- [ ] Поток данных отслежен
- [ ] Граничные условия проверены
- [ ] Обработка ошибок проверена
- [ ] Побочные эффекты отсутствуют
- [ ] Зависимости проверены

---

## Примеры Использования

### Пример 1: Dry Run для PowerShell

**Скрипт:**
```powershell
function Get-Files($path) {
    Get-ChildItem $path | Where-Object { $_.Extension -eq ".md" }
}
```

**Dry Run:**
```markdown
**Dry Run Report:**

**Скрипт:** Get-Files.ps1

**Поток данных:**
1. Вход: $path (строка)
2. Get-ChildItem $path → список файлов
3. Where-Object → фильтрация по .md
4. Выход: список .md файлов

**Граничные условия:**
- ✅ Пустая директория → пустой список
- ✅ Несуществующий путь → ошибка Get-ChildItem
- ✅ Нет .md файлов → пустой список

**Обработка ошибок:**
- ⚠️ Нет try/catch для Get-ChildItem
- Рекомендация: Добавить обработку ошибки

**Побочные эффекты:**
- ✅ Нет изменений файлов
- ✅ Нет сетевых вызовов
- ✅ Нет блокировок

**Вердикт:** ✅ Логика корректна, рекомендуется добавить обработку ошибок
```

### Пример 2: Dry Run для Batch

**Скрипт:**
```batch
@echo off
set "COUNT=0"
for %%f in (*.md) do set /a COUNT+=1
echo Найдено %COUNT% файлов
```

**Dry Run:**
```markdown
**Dry Run Report:**

**Скрипт:** count_files.bat

**Поток данных:**
1. Инициализация: COUNT=0
2. Цикл for по *.md файлам
3. Инкремент COUNT для каждого файла
4. Вывод результата

**Граничные условия:**
- ✅ Нет .md файлов → COUNT=0
- ✅ 1 файл → COUNT=1
- ✅ 100 файлов → COUNT=100

**Обработка ошибок:**
- ✅ Ошибок нет

**Побочные эффекты:**
- ✅ Нет изменений файлов
- ✅ Нет сетевых вызовов

**Вердикт:** ✅ Логика корректна
```
