# Навык: Инструменты Командной Строки (rg, sd)

Этот документ содержит инструкции по использованию ключевых утилит командной строки: `ripgrep` (rg) для поиска и `sd` для замены.

---

## 1. Ripgrep (rg) - Поиск

### 1.1. Стандарт вызова (Обязательно)
Всегда используй эти флаги для корректного и полного поиска:
- `-nH` — Показывать **имя файла и номер строки**. Критически важно для навигации.
- `-i` — **Игнорировать регистр**. Всегда использовать для русского языка.
- `--no-ignore` — Искать во всех файлах, даже тех, что в `.gitignore`.

### 1.2. Сценарии поиска
- **Общий поиск текста**: `rg -nH -i "паттерн" .` (точка `.` означает "в текущей директории").
- **Поиск по типу файла**: `rg -nH -i -t md "задача" .` (искать только в Markdown).
- **Поиск точной строки (без regex)**: `rg -nH -i -F "Спец.Символы[]()"`

### 1.3. Фильтрация
- **Исключить "мусор"**: `rg -nH -i -g '!sessions/*' -g '!.pi/*' "запрос" .`
- **Искать в конкретном файле**: `rg -nH -i "ошибка" ./todo.md`

### 1.4. Запреты (Критично)
- **ЗАПРЕТ**: Использовать `-p`, `--color`, `--stats`. Они ломают парсинг.
- **ЗАПРЕТ**: Использовать `-r` (replace). Для замены есть `sd` и инструмент `replace`.

---

## 2. sd - Поиск и Замена

### 2.1. Базовый синтаксис
`sd [ОПЦИИ] <ЧТО_ИСКАТЬ> <ЧЕМ_ЗАМЕНИТЬ> [ФАЙЛЫ]...`

### 2.2. Важные флаги
- `-F, --fixed-strings` — Искать **точную строку**, а не регулярное выражение.
- `-p, --preview` — **Предпросмотр** изменений без записи в файл. Использовать для безопасности.
- `-n, --max-replacements <N>` — Максимум N замен на файл.

### 2.3. Сценарии замены
- **Простая замена строки:**
  `sd -F "старый_текст" "новый_текст" C:\project\file.txt`
- **Замена с предпросмотром:**
  `sd -p -F "TODO" "DONE" C:	asks\*.md`
- **Замена с использованием regex групп:**
  `sd "(\d{4})-(\d{2})-(\d{2})" "$3.$2.$1" C:\logs\date_log.txt`

### 2.4. Правила безопасности (Критично)
- **Синтаксис путей Windows:** Всегда используй двойные обратные слэши (`C:\project\file.txt`).
- **Предпросмотр:** Всегда используй `-p` для проверки сложных замен.
- **Контекст:** Перед массовой заменой убедись, что шаблон не затронет лишнего.
