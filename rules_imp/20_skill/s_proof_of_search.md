## Назначение

Этот навык обеспечивает **абсолютную правдивость** утверждений агента о коде и данных через механизм **Proof of Search** (доказательство поиска).

---

## Формат Proof of Search

Каждая ссылка на код/данные **ОБЯЗАНА** содержать:

```markdown
**Proof of Search:**
- Команда: `rg -nH "термин" путь`
- Файл: `имя_файла`
- Строка: `номер`
- Цитата: "прямая выдержка из файла"
- Вердикт: "Данные взяты из исходника на диске"
```

---

## Команды Поиска

### Базовый поиск

```bash
# Поиск термина с номерами строк
rg -nH "термин" путь/к/файлу

# Поиск с контекстом (2 строки до и после)
rg -nH -C 2 "термин" путь

# Поиск по нескольким файлам
rg -nH "термин" *.md

# Поиск с игнорированием регистра
rg -inH "термин" путь
```

### Расширенный поиск

```bash
# Поиск по типу файла
rg -nH --type py "def функция" путь

# Поиск с исключением директорий
rg -nH "термин" путь --ignore-dir node_modules

# Поиск точной фразы
rg -nH "точная фраза" путь

# Поиск по шаблону (regex)
rg -nH "function\s+\w+" путь
```

## Протокол Применения

### Шаг 1: Перед утверждением о коде

**ОБЯЗАТЕЛЬНО** выполнить поиск:
```bash
rg -nH "утверждаемый_факт" путь
```

### Шаг 2: Фиксация результата

**Если найдено:**
```markdown
**Proof of Search:**
- Команда: `rg -nH "функция" rules_imp/`
- Файл: `p_safe_edit.md`
- Строка: 12
- Цитата: "Каждая ссылка на код/данные должна содержать: команду поиска, файл, строку, цитату."
- Вердикт: Данные взяты из исходника на диске.
```

**Если НЕ найдено:**
```
Информация не найдена в файлах проекта. Требуется уточнение.
```

### Шаг 3: Проверка зависимостей

**Перед импортом модуля:**
```bash
# Для Node.js
rg "\"название_модуля\"" package.json

# Для Python
rg "^название_модуля" requirements.txt

# Для Rust
rg "название_модуля" Cargo.toml
```

**Если зависимость не найдена:**
```
Зависимость "название_модуля" не найдена в [файл]. Требуется установка.
```

## Примеры Использования

### Пример 1: Утверждение о функции

**Запрос:** "Где определена функция safe_edit?"

**Ответ агента:**
```markdown
**Proof of Search:**
- Команда: `rg -nH "safe_edit" rules_imp/10_proc/`
- Файл: `p_safe_edit.md`
- Строка: 1
- Цитата: "# Протокол Безопасного Редактирования и Удаления (p_safe_edit.md)"
- Вердикт: Данные взяты из исходника на диске.

Функция `safe_edit` определена в файле `rules_imp/10_proc/p_safe_edit.md`.
```

### Пример 2: Утверждение о зависимости

**Запрос:** "Установлен ли ripgrep?"

**Ответ агента:**
```markdown
**Proof of Search:**
- Команда: `rg "\"ripgrep\"" package.json`
- Файл: `package.json`
- Строка: НЕ НАЙДЕНО
- Вердикт: Зависимость не найдена в package.json

**Действие:** Проверить установку через `rg --version`
```

### Пример 3: Частичное выполнение (честный отчёт)

**Запрос:** "Найти все упоминания Конституции в 30 файлах"

**Ответ агента:**
```markdown
**Честный отчёт о частичном выполнении:**

**Найдено:** 20 из 30 файлов (67%)

**Proof of Search:**
- Команда: `rg -nH "Конституция" rules_imp/`
- Файлов найдено: 20
- Файлов не найдено: 10

**Список найденных файлов:**
1. constitution.md — 15 упоминаний
2. id.md — 3 упоминания
...

**Список ненайденных файлов:**
1. [файл1] — не содержит "Конституция"
2. [файл2] — не содержит "Конституция"
...

**Предложение:** Повторить поиск через 5 минут с другими терминами.
```
