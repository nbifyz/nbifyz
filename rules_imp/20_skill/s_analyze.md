# 🔍 Скилл 2: Анализ кода без выполнения

## Правило

**ВСЕГДА** выполнять сухой прогон - анализ логики функции БЕЗ её запуска.

## Что такое сухой прогон

Анализ логики функции "на бумаге" - понимание что делает каждая строка кода.

## Уровни сухого прогона

### 1. По функциям
```
- Пройтись по каждой функции
- Понять входные данные
- Понять выходные данные  
- Проверить все ветвления
- Проверить все циклы
```

### 2. По модулям
```
- Понять связи между модулями
- Проверить поток данных
- Проверить импорты
```

### 3. По системе в целом
```
- Понять общий поток выполнения
- Проверить порядок вызова функций
- Проверить побочные эффекты
```

## Пример

```python
def process_file(path):
    # Сухой прогон:
    # 1. Принимает path (строка)
    # 2. Проверяет exists(path)
    # 3. Если не существует -> error
    # 4. Если существует -> читает файл
    # 5. Возвращает содержимое
    if not os.path.exists(path):
        return None
    with open(path, 'r') as f:
        return f.read()
```

## Когда применять

- ✅ Перед написанием кода
- ✅ После изменения кода
- ✅ Перед тестированием
- ✅ При отладке
