# Индекс Инструментов Агента

Этот файл служит каталогом для всех исполняемых инструментов (`.py`, `.bat`), доступных агенту.

| Файл | Назначение |
| :--- | :--- |
| `check_compliance.py` | Проверяет код на соответствие стандартам. |
| `dry_run_analyzer.py` | Выполняет статический анализ кода ("сухой прогон") для поиска логических ошибок. |
| `hallucination_detector.py` | Используется для проверки ответов и действий на предмет галлюцинаций. |
| `integrated_checker.py` | Комплексный скрипт, объединяющий несколько проверок. |
| `run_comprehensive_check.bat` | Пакетный файл для запуска полного цикла проверок (compliance, dry run и т.д.). |
