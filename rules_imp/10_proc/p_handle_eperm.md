# Протокол Обработки Ошибок Доступа (p_handle_eperm.md)

Этот протокол **обязателен** для выполнения при возникновении ошибки доступа к файлу `EPERM: operation not permitted`.

---

## Полный 4-шаговый Процесс

1.  **Диагностика:** В первую очередь проверить, не установлен ли на файле атрибут "только для чтения".

2.  **Исправление:** Если атрибут установлен, попытаться снять его командой PowerShell:
    `Set-ItemProperty -Path [путь_к_файлу] -Name IsReadOnly -Value $false`

3.  **Обходной маневр:** Если снятие атрибута невозможно или не решает проблему, применить стратегию "создать новый -> удалить старый -> переименовать новый".

4.  **Крайний случай:** Если все вышеперечисленное не помогает, сообщить пользователю о проблеме, предоставить ему готовый контент для ручного внесения изменений и ожидать дальнейших инструкций.
