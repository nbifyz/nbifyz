# Правила использования утилиты SD
    *Для внесения изменений в JSON и другие текстовые файлы используй инструмент sd (search & displace).
    Базовый синтаксис:
    sd "ШАБЛОН" "ЗАМЕНА" ПУТЬ_К_ФАЙЛУ

    Важные особенности:
        По умолчанию заменяет все совпадения по всему файлу (как s/.../.../g в sed).
        Если просто найти и заменить простой текст, можно использовать режим простых строк (флаг -s), чтобы символы вроде . или * не считались специальными.
        Для замены с переносом строк добавь флаг -A.

## Примеры:

1. Текстовая замена: sd "old_value" "new_value" data.txt
2. Работа с JSON: sd '"old"' '"new"' progress.json
3. Режим простой строки: sd -s "projects/*.exe" "projects/binaries/*.exe" config.toml
