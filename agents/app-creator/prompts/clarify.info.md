# /clarify

Прочитай `./rules/spec_principles.md`, раздел 5.
Проанализируй `Prj/spec.md` на наличие `[NEEDS CLARIFICATION]`.
Задай вопросы пользователю по таксономии (7 категорий).
Формат: multiple-choice (A/B/C/D) или короткий ответ ≤5 слов.
Рекомендуемый вариант — первым.
После каждого ответа — обнови `Prj/spec.md` в секции `## Clarifications`.
