# /switch-model

## Шаг 1: Узнать текущую модель

Вызови:
```
curl -s http://127.0.0.1:5001/v1/models
```
Из ответа извлеки `id` модели. Запомни как `CURRENT_MODEL`.

## Шаг 2: Определить нужную модель

Прочитай `./task.md`. Сопоставь задачу с моделью:

| Задача | Модель | Bat-файл |
|--------|--------|----------|
| Реализация, быстрые ответы, tool calling | Qwen 3.6-35B | `qwen_no_think.bat` |
| Ревью, анализ, поиск ошибок, верификация | Gemma 4-27B | `gemma_think.bat` |

## Шаг 3: Если модель уже правильная

Сообщи: "Модель уже запущена. Продолжаю."
Продолжай выполнение задачи.

## Шаг 4: Если нужна другая модель

1. Сообщи: "Переключаю [старая] на [новая]."
2. Запиши в `./current_llm.md`: `model: [новая]`
3. Останови сервер:
   ```
   taskkill /F /IM llama-server.exe
   ```
4. Запусти новый bat-файл:
   ```
   start "" "E:\AI\Llama.cpp\[нужный_bat].bat"
   ```
5. Проверяй готовность каждые 5 секунд:
   ```
   curl -s http://127.0.0.1:5001/v1/models
   ```
   Не ответил — жди ещё 5 секунд и повтори.
6. Ответил — сообщи: "Модель [новая] готова. Продолжаю."

## Шаг 5: Продолжить работу

После переключения продолжи выполнение задачи из `./task.md`.
