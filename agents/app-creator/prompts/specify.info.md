# /specify

Прочитай `./rules/spec_principles.md`, разделы 1 и 2.
Возьми описание задачи из `../task.md`.
Создай спецификацию в `Prj/spec.md` по шаблону:
- User Scenarios & Testing (P1, P2, P3)
- Requirements (FR-001, FR-002...)
- Key Entities
- Success Criteria
- Edge Cases
Если есть неясности — пометь `[NEEDS CLARIFICATION]`.
В конце создай чеклист качества в `Prj/checklists/requirements.md`.
